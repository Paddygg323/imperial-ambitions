# Source and asset notes

This is a project-private design/development handover. No open-source license has been selected or added.

The numbered reference sprite set came from the owner's shared concept page; its URL and original checksums are recorded in the sprite-library manifest. Many subsequent revisions were generated during this project; available exact prompts are kept beside the images.

`docs/design-references/` contains owner-supplied UI concepts and original-game screenshots for visual comparison. These are references, not exported game assets.

Some game data, technology text, historical geometry and investigations were extracted or derived from the original Imperialism II. Relevant source notes remain in `game/data/` and `outputs/`. This private repository does not assert that those materials are cleared for a public commercial release.

The Windows game installation, executable, commercial manual PDFs, PC hotseat project, personal campaign saves, signing keys and deployment credentials are not bundled.
