# Historical development tools

These are preserved one-off scripts used during earlier implementation and visual iterations. They are not the normal startup, test or Android build path.

Many expect files on the original development machine, original-game extraction inputs, old source text, or generated images outside this repository. They are retained for context, not as a reproducible ordered migration chain.

Use the root README commands for current work. Read an individual script before running it. Never run this whole directory automatically.
